# Лабораторная 2 — Generic Host

## Реализация
- Generic Host и `BackgroundService` управляют жизненным циклом.
- `IRandomSource`, `IStudentStrategy`, `SemesterEmulator` и набор преподавателей подключены через DI.
- В конце каждой успешной итерации печатаются накопленное удовольствие и среднее за прошедшие дни.
- При вылете удовольствие сбрасывается в 0, и цикл прекращается.

Стратегия осторожная: посещает пары со случайным правилом, а прогуливает только пары, где детерминированное правило заранее предсказывает отсутствие опроса.
